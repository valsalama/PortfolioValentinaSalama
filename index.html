Bases de datos
Python y React

MediPlus

Sistema para una prepaga de salud que usa cuatro bases de datos, cada una para lo que mejor resuelve. MongoDB guarda los 1000 afiliados con su plan, domicilio y enfermedades. Neo4j modela el grafo de afiliados, grupos familiares, médicos, clínicas y medicamentos. Redis maneja sesiones, caché y reserva temporal de turnos, y el ranking de médicos más demandados. Cassandra almacena las tablas de consulta para los tableros de gastos, medicamentos, especialidades y clínicas. El backend es una API en Python con FastAPI y el frontend está hecho en React: desde un mismo panel se consulta, crea, actualiza o elimina un registro, y la operación se ejecuta en cada base mostrando el resultado y la consulta usada, junto con una vista en grafo de las relaciones.
